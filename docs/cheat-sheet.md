# Cheat sheet: what you can type

## In your Slack inbox channel (top-level)

| Type | Example | Result |
|---|---|---|
| Blocker | `block tomorrow 10-12` | conflict check → blocker in both calendars |
| Recurring blocker | `block Mon Wed Fri 9-11 deep work` | 3 × "Focus: deep work" |
| Private | `gym today 18-19:30` | private blocker; work sees "Blocker" |
| Remove | `delete tomorrow's blocker` | removes the blocker and its mirror |
| Task | `send report to Jamie by friday` | task, due Friday |
| Note | `note: …` / `learning: …` / `info: …` | knowledge entry |
| Question | `question: who owns tracking?` | knowledge entry (Open question) |

## As a thread reply

| Under… | Reply | Result |
|---|---|---|
| 📨 proposal | `ok` | task as proposed |
| 📨 proposal | `ok prio: high, project: funnel, due: tomorrow, task: <text>` | task with overrides |
| 📨 proposal | `knowledge` | knowledge entry instead |
| 📨 proposal | `info` | done task "Info: …" |
| 📨 proposal | `skip` | discarded |
| ⚠️ conflict | `1` / `2` | take an alternative |
| ⚠️ conflict | `anyway` | create despite the conflict |
| ⚠️ conflict | `14-15` | try a new time |

## Post icons you'll see

| Icon | Meaning |
|---|---|
| 📨 | request for you; confirm it |
| ✅ | task/blocker created |
| 🧠 | stored in the knowledge log |
| 📞 | meeting processed |
| ℹ️ | FYI, nothing to do |
| ⚠️ | conflict or error |
| 🗑 | please delete manually |
| 🔄 | sweep summary |
| ☀️ / 📊 | morning brief / weekly review |
